# Отчет по проекту Finance Roguelike

Проект сейчас находится на стадии рабочего браузерного прототипа мобильной игры с tab-based интерфейсом. Основа игры уже собрана: есть run loop, экономика, события, выборы, покупка и улучшение бизнесов, макроэкономика, синергии, временные модификаторы, локализация RU/EN и мобильный UI с нижней навигацией.

## Что уже сделано

### 1. Игровой цикл

- Реализована партия на 10 ходов.
- Каждый ход считает экономический результат игрока.
- После расчета хода игрок получает событие.
- Игрок выбирает решение по событию.
- Затем игрок делает одно действие: купить актив, улучшить актив, сыграть карту, продать актив.
- После завершения обязательных шагов активируется `Next Turn`.
- Есть завершение партии по лимиту ходов и поражение по банкротству/долговому давлению.

### 2. Экономика

- Есть базовые метрики:
  - `Cash`
  - `Profit`
  - `Debt`
  - `Valuation`
- Есть расчет:
  - доходов,
  - расходов,
  - процентов по долгу,
  - итоговой прибыли,
  - капитализации.
- Доходность бизнеса зависит от:
  - уровня бизнеса,
  - спроса,
  - инфляции,
  - стоимости энергии,
  - синергий,
  - модификаторов от событий и карт.
- Долг влияет на нагрузку через проценты.
- При слишком высоком долге срабатывает риск банкротства.

### 3. Бизнесы и активы

- Добавлен data-driven набор бизнесов.
- У каждого бизнеса есть:
  - отрасль,
  - стоимость,
  - доход,
  - расход,
  - риск,
  - чувствительность к макро-факторам,
  - лимит уровней.
- Игрок может:
  - покупать бизнесы,
  - улучшать бизнесы,
  - продавать бизнесы.
- Бизнесы отображаются в `Portfolio` и `Market`.

### 4. Отрасли

- Добавлены отрасли:
  - retail,
  - it,
  - logistics,
  - manufacturing,
  - energy,
  - real_estate,
  - media.
- Отрасли используются:
  - для фильтров,
  - для условий событий,
  - для смысловой разницы между бизнесами,
  - для определения синергий и макро-влияния.

### 5. События

- Есть пул из 20 событий.
- У событий есть:
  - `weight`,
  - условия появления,
  - макро-эффекты,
  - choices.
- Условия появления учитывают:
  - номер хода,
  - долг,
  - спрос,
  - стоимость энергии,
  - наличие нужных отраслей у игрока.
- Это делает ран не полностью случайным, а частично контекстным.

### 6. Выборы и карты решений

- У событий есть варианты решений.
- Есть отдельные decision cards.
- Решения и карты могут влиять на:
  - деньги,
  - риск,
  - долг,
  - доходность,
  - расходы,
  - макро-параметры.
- В браузерном UI choices и cards показываются отдельно на вкладке `Decisions`.

### 7. Временные модификаторы

- Это последний реализованный шаг по roadmap.
- Часть эффектов событий и карт теперь не постоянные, а временные.
- Для них добавлены:
  - `temporary_effects`
  - `duration_turns`
- Модификаторы живут 2-3 хода.
- Каждый новый ход уменьшает их длительность.
- После истечения они удаляются.
- Временные эффекты влияют на:
  - `revenue_bonus`
  - `expense_bonus`
  - `risk`
  - при необходимости на макро-параметры
- Они уже учитываются в расчете эффективной экономики и показываются в UI.

### 8. Синергии

- Реализована система синергий между активами.
- Есть 10 синергий.
- Синергия активируется, если игрок владеет нужной комбинацией бизнесов.
- Синергии дают бонусы к:
  - доходу,
  - расходам.
- В `Portfolio` показываются:
  - активные синергии,
  - почти собранные синергии.

### 9. Логирование партии

- Для текстового прототипа был добавлен run log.
- Лог сохраняет:
  - события по ходам,
  - выборы,
  - действия игрока,
  - изменения компании.
- Это нужно для балансировки и анализа ранoв.

### 10. Браузерный интерфейс

- Убрана длинная вертикальная страница.
- Сделана мобильная app-структура.
- Реализованы вкладки:
  - `Dashboard`
  - `Decisions`
  - `Portfolio`
  - `Market`
  - `Economy`
- Есть `fixed bottom navigation`.
- Центральная часть рендерит только активную вкладку.
- Header компактный:
  - turn counter,
  - status hint,
  - 2x2 grid метрик,
  - `Next Turn`.
- UI стилизован под clean luxury fintech / mobile app.

### 11. Языки и локализация

- Добавлен экран выбора языка при первом запуске.
- Поддерживаются:
  - `Русский`
  - `English`
- Выбор сохраняется в `localStorage`.
- При повторном запуске язык не спрашивается.
- Есть кнопка смены языка без сброса текущего run.
- Основные интерфейсные тексты вынесены в словарь `translations`.
- Используется функция `t(key)`.

### 12. Иконки вкладок

- Текстовые заглушки вкладок удалены.
- Добавлены PNG-иконки для:
  - Dashboard
  - Decisions
  - Portfolio
  - Market
  - Economy
- Иконки используются в нижней навигации.
- Активная вкладка выделяется фоном и повышенной видимостью иконки.

## Какие механики уже работают

### 1. Run loop

- старт партии;
- ходовая структура;
- переход между ходами;
- завершение партии.

### 2. Core economy

- расчет прибыли;
- стоимость обслуживания долга;
- капитализация;
- денежный поток.

### 3. Macro system

- процентная ставка;
- инфляция;
- спрос;
- стоимость энергии;
- доступность кредита;
- рыночный риск.

### 4. Business system

- покупка;
- улучшение;
- продажа;
- фильтрация по категориям;
- рыночный список доступных активов.

### 5. Event system

- weighted event selection;
- условия появления;
- choices внутри события;
- эффект события на run.

### 6. Decision system

- решение по событию;
- отдельные action cards;
- один meaningful шаг игрока на ход после события.

### 7. Temporary modifier system

- баффы/дебаффы на несколько ходов;
- автоматическое истечение;
- влияние на формулы экономики.

### 8. Synergy system

- активация по наборам активов;
- бонусы;
- отображение активных и почти собранных комбинаций.

### 9. UI state system

- `activeTab`
- `selectedLanguage`
- `languageModalOpen`
- `eventResolved`
- `pendingActionDone`

### 10. Localization system

- RU/EN словарь;
- локализованные вкладки;
- локализованные статусы;
- локализованные CTA.
